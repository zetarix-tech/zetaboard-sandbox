# zetaboard-sandbox

**Repo de prueba de la plataforma. No es un producto y no tiene código real.**

Existe para probar la GitHub App `zetaboard` contra GitHub de verdad, sin
tocar ningún repo productivo: instalación de la App, vínculo proyecto ↔ repo,
protección de la rama base, y más adelante el flujo completo de PR
(branch → PR → check del criterio → merge squash).

Es público a propósito: la org está en plan Free, donde los rulesets sólo
existen en repos públicos — con uno privado la protección respondería
`no_disponible_en_plan` y la prueba quedaría a medias.

Se puede borrar en cualquier momento.
